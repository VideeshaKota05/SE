## 1. What is static code analysis?

Static code analysis is the process of examining source code without executing it. It helps identify bugs, security vulnerabilities and coding style violations before deployment.

## 2. What did you learn from the three tools?

Pylint helped identify code quality issues, naming convention violations and programming mistakes.

Bandit helped identify security vulnerabilities, including unsafe SQL queries and insecure random number generation.

Flake8 helped identify formatting issues and violations of Python's PEP 8 guidelines.

## 3. What issues did you fix?

I fixed SQL injection vulnerabilities using parameterized queries, replaced random with secrets, corrected mutable default arguments, improved exception handling, followed Python naming conventions and added documentation strings.

## 4. Why is static code analysis important?

Static code analysis improves software quality, security, readability and maintainability. Using multiple tools helps developers identify different categories of problems early. Functional testing is also necessary to verify that the application works correctly.
