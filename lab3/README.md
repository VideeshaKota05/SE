## Deliverables

## Architecture
Layered Architecture

## Description
This project presents the architecture of a Pharmacy Inventory Management System.

The system consists of:
- Staff Dashboard
- Supplier Portal
- Inventory and Batch Management
- FEFO Stock Allocation
- Expiry Monitoring and Alerts
- Purchase Order Management
- Pharmacy Database
- Reports and Performance Benchmarking
